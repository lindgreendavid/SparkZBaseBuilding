# SparkZ Marker Icons

Put SparkZ-owned marker icons in this folder as `.paa` files.

Packed mod path:

```text
SparkZGroup\gui\icons\markers\your_icon.paa
```

Source folder:

```text
C:\Users\dave7\Desktop\SparkZ_Modpack\SparkZGroup\gui\icons\markers
```

Use this folder for icons that SparkZ is allowed to redistribute. Do not reference icons from another mod folder directly in final builds.
